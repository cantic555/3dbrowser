# 3D Browser

ブラウザの中に、厚みのある 3D のブラウザを表示する Web アプリです。
やたら縦に長いケノン脱毛(未購入)のサイトからひらめいて作りました。

**▶ https://3dbrowser.cantic.org/**

A web app that shows a thick, rotatable 3D browser inside your browser.

## できること

- 箱の形をしたブラウザを、ドラッグや操作パネルで回す・拡大縮小する（パネルは右下に縦一列: 上から 拡大縮小のレバーとパンのレバー ✋ (横に並ぶ)、回転のレバー 🌐、平行回転のレバー（左の端に ⟲、右の端に ⟳）。片手の親指で届き、真ん中を空けるため。横持ちのスマホなど高さが足りない画面では、左下に回転と平行回転、右下に拡大縮小とパンに分かれる。しばらく触らないと薄くなる）
- 左上の 🗺️ で全体マップのオン・オフ（拡大中に左上に出る地図。選んだ状態は覚えておく）
- 左上の虫めがね 🔍 をドラッグして、箱の上の好きな所に落とすと、そこを拡大する（縦長の箱は幅いっぱい、ほかは 2 倍。向きはそのまま。端の近くに落としても、箱の外の背景が見えすぎないよう画面に合わせる。拡大中は虫めがねに「−」の印が付き、押すだけで全体表示に戻る）
- 拡大したまま見る場所を動かす: 拡大中（箱がはっきりはみ出しているとき）は、背景や枠をドラッグするとパンになる（地図と同じ。PC ではカーソルが手のひらになる。はじくと少し動き続ける）。ほかに Shift + ドラッグ・右ドラッグ・Shift + 矢印キー（スマホは 2 本指で動かす）。ホイール（ページの上では Ctrl + ホイール）はカーソルに向かって拡大する。箱が画面からはみ出すと左上に全体マップが出て、クリック・ドラッグでその場所へ移れる
- 中心から離れた所を円を描くようにドラッグ（スマホは 2 本指でひねる、パネルの平行回転のレバー）で、画面に平行に回す（トラックボール方式: 中心近くのドラッグは傾くだけ、離れるほどロールが混ざる。箱が逆さまやロール中でも、ドラッグ・スティック・矢印キーは見た目どおりの向きに回る）
- 操作パネルのロック（3 つ同時にも使える。「リセット」で全部止まる）
- 「リセット」は 1 段ずつ戻り、押し続けると最後はトップ画面（スタートページ）: 向きと大きさを戻す → もう一度でトップ画面。縦長のゲームなどで箱が超縦長になっているときは、1 回目は大きさを保って向きと位置だけ、2 回目で標準の大きさ、3 回目でトップ画面
- 「全体」（スマホでは ⤢）は向きを変えずに箱全体を画面に収め、「軸合わせ」（📐）は向きを一番近いまっすぐな向き（0・90・180 度）にそろえる。キーボードでは F と A
  - 平行回転のレバーは右に倒すと時計回り、左に倒すと反時計回り（深く倒すほど速い）。倒したままじっとして輪が一周してから離すと、その速さで回り続ける（レバーを触ると止まる）
  - 拡大縮小のレバーは手前に引く（下に倒す）と拡大、押しやる（上に倒す）と縮小（深く倒すほど速い）。倒したままじっとして輪が一周してから離すと、その速さで続け、極大と極小の間をループして、突き抜けて遠くからまた現れる（レバーを触ると止まる）
  - スティックを倒したまま 2 秒じっとして離すと、その位置（速さ）のまま回り続ける（スティックに触れると止まる）
  - 回転のレバーを上下左右にすばやくはじくと、その向きに 180 度回って裏側が見える（続けてはじくと 360 度）
  - 回転のレバーをダブルクリック（ダブルタップ）すると回転禁止（🔒）。背景のドラッグは視点の移動になり、レバーや矢印キーでも回らない。もう一度ダブルクリックするか、レバーをドラッグするか、🔒 を押すと解除。パンのレバーも同じく、ダブルクリックでパン禁止（拡大縮小のレバーも止まる）
- 右下の角をドラッグしてブラウザの大きさを変える（どの面でも。ブラウザにしていない面でもよい。側面・上下の面では箱の厚みも変わり、最大で立方体まで）。黄の丸で最小化、緑の丸で最大化。右下の「サイズ」からスマホ・タブレット・ワイドなどの大きさを選べる
- アドレスバーに `about:tall` と入れると、やたら縦に長いケノン脱毛のサイトを縦に長いブラウザで一望できる
- 前面だけでなく、側面・背面もクリックでブラウザにできる（タブはドラッグで別の面へ移動）
- 検索語は Wikipedia を検索、URL はそのサイトを表示（iframe）。YouTube の動画ページの URL は埋め込みに変えて再生できる（公開サイトのような https で開いたとき）
- 「透過」で反対側の面を透かして見る（長押しでスライダーが出て、上下に動かすと透け具合を変えられる。動かさずに離すとスライダーは出たままになり、直接ドラッグできる。「リセット」で透過も透け具合も元に戻る）。透過中は、小人とお絵描きのページはガラスのように背景が透明になり、描いたものだけが見える
- 日本語 / English の切り替え

### 内蔵ページ

| アドレス | 内容 |
|---|---|
| `about:this` | この 3D Browser 自身（ブラウザの中のブラウザの中の…） |
| `about:draw` | お絵描き。描いた線を蝶のように飛ばせる |
| `about:horror` | ちょっと怖い？（Esc でスキップ） |
| `about:kobito` | 小人（Tiny Folks）が暮らしている。回すとあたふたする。何もない所をドラッグすると線が引けて、小人はその上を歩く（線はドラッグで移動、ダブルクリックで消す。すばやく振り上げると乗っている小人が飛んでいく） |
| `about:lphone` | 超縦長のスマホ「lPhone」。箱全体がスマホの形（角丸・ボタン・カメラ・バナナのロゴ）になり、細長いホーム画面からアプリを開ける。拡大中はホーム画面の空いた所をドラッグすると、スマホをスクロールするように上下にパンする（リセットは 1 段ずつ戻る: アプリを使っていたら表示位置だけ → ホーム画面 → 3D Browser）。ロールで横にすると、サイト（外のサイトと検索）の表示が横向きに自動で回って超横長になる（ホーム画面と内蔵のアプリは縦のまま、逆さまでは回らない）。ホーム画面の「バッテリー」アプリで、充電の % とあと何日もつかが分かる（電池は本体の体積に比例） |
| `about:shogi` | ナガ将棋。縦に長い 9 × 27 の盤（9 × 9・9 × 81・9 × 7・9 × 6 も選べる）で、本将棋のルール（二歩・打ち歩詰め・王手放置の禁止、詰みで勝ち、千日手は引き分け）。最初は CPU どうしのオートで、右の縁の ☗ で出す操作パネルから、再生・停止・速さ（×1〜×32）、先手・後手それぞれの人 / CPU の切り替えと CPU の強さ（よわい: 1 手だけ読む / ふつう・強い: 先を読む）、盤の大きさ、音・残像などを選べる。人の番は駒をタップして行き先をタップ（持ち駒は盤へドラッグでも打てる）。勝負がつくと、取った駒の数のランキングと MVP が出る。スタートページでは「アーケード」のフォルダの中（lPhone のホーム画面では「将棋」） |
| `about:info` | 操作方法などの説明 |

お絵描き・ホラー・小人・スマホ（lPhone）はプラグイン（`plugins/*.js`）になっています。作り方は下の「内蔵ページを追加する」を見てください。

URL に `?url=about:…` を付けて開くと、最初からその内蔵ページが開きます（例: `https://3dbrowser.cantic.org/?url=about:lphone`）。スマホなど箱の形が変わるページも、変身の途中を見せずに最初からその形で開きます。指定できるのは内蔵ページだけで、外のサイトや検索語、ないページを指定したときは、いつものスタートページになります。

## 注意

iframe を使っているため、埋め込みを拒否している多くのサイト（Google、X など）は中に表示されません。

## 動かし方

`index.html` と `plugins/` フォルダだけで動きます。外部ライブラリは不要なので、`index.html` をブラウザで直接開くか、好きな静的サーバーで配信してください。

## 内蔵ページを追加する

`plugins/` に JS ファイルを置いて `node build-plugins.mjs` を実行すると、`index.html` に読み込みが追加され、`about:<id>` で開けるようになります（スタートページのボタンと説明ページの一覧にも出ます）。

```js
// plugins/hello.js
B3D.registerPage({
  id: 'hello',                          // about:hello で開く
  title: 'hello',                       // タブ名 (strings のキー)
  info: 'helloInfo',                    // 説明ページの一覧に出す説明
  menu: true,                           // スタートページと説明ページに並べる
  strings: { hello: ['こんにちは', 'Hello'], helloInfo: ['あいさつ', 'Greetings'] },  // [日本語, English]
  css: `.hello { padding: 40px; font-size: 32px; }`,
  render(tab, api) {                    // ページの中身を作る
    const el = document.createElement('div');
    el.className = 'hello';
    el.textContent = api.t('hello');
    tab.pane.appendChild(el);
  },
});
```

`api` から本体の機能を使えます（面の向き・重力、面の外への 3D 表示、毎フレームの処理、ページ間のアイテムの受け渡しなど）。中身は `index.html` の `pageApi` を見てください。

## デプロイ (Cloudflare)

```
node deploy.mjs            # 公開する
node deploy.mjs --dry-run  # アップロードせずに確認だけ
```

`node build-plugins.mjs` を実行してから、`index.html`・`plugins/`・`LICENSE` を `dist/` に集めて、`wrangler deploy` で Cloudflare Workers に配信します（設定は `wrangler.toml`）。
